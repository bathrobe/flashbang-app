# Sound credits

All five sounds are by Kenney (www.kenney.nl), released under CC0 (public domain):
http://creativecommons.org/publicdomain/zero/1.0/

Each was converted from the pack's `.ogg` to `.mp3` (ffmpeg, LAME VBR quality 4) so every browser plays it.
To swap one, drop a new `.mp3` in this folder with the same name and update this table.
